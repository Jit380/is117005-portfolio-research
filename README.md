# IS 117005 · AI Career Research Portfolio

A VitePress research site exploring emerging AI careers, job descriptions, and real opportunities across New York and New Jersey.

**GitHub Pages:** [AI Career Atlas](https://Jit380.github.io/is117005-portfolio-research/)

The URL above is the intended deployment address. Publication is complete only after the GitHub Pages deployment succeeds.

## Research scope

- AI engineering, forward deployed engineering (FDE), security, systems/IT, infrastructure, operations, evaluation, and governance.
- Internship, entry-level, mid-level, and senior opportunities.
- BLS occupation context, primary research, and individually verified employer postings.
- Exact source links, location and qualification details, and dates checked.

## Local development

Requires Node.js 22 or newer.

```sh
npm ci
npm run docs:dev
```

```sh
npm run docs:build
npm run docs:preview
```

Content lives in `docs/`; VitePress configuration and theme live in `docs/.vitepress/`.

## GitHub Pages

In repository Settings → Pages, select **GitHub Actions** as the build source. The included workflow builds and deploys pushes to `main`. The configured base path is `/is117005-portfolio-research/`.

Research snapshot: November 5, 2026. A posting is evidence of an individual vacancy, not evidence of title-wide growth. See the site's Sources page for methodology.
